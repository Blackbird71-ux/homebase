# One-Off Chores — Implementation Plan

## Summary

Add "one-off" as a new frequency option for chores. A one-off chore has a specific due date (like a deadline), is completed once, and is then deactivated with no next occurrence. All existing features (assignees, notes, descriptions, email reminders, early completion) continue to work.

## Approach

Add "one-off" as a new frequency value alongside the existing daily/weekly/biweekly/monthly/bimonthly/quarterly/halfyearly/yearly. No new database fields are needed — the existing frequency string field already supports arbitrary values.
