Simple Budget Planner -- Implementation Plan
=============================================

1. OVERVIEW
===========

Add a standalone Simple Budget Planner page to the existing Homebase app. It lives
alongside the Finance section but is NOT linked to the accounting system -- pure
budget tracking for non-finance users. A Settings toggle shows/hides the nav link.

Key Design Decisions:
- Data storage: New Prisma model BudgetPlannerItem (SQLite)
- Preference storage: uiPreferences.showBudgetPlanner (existing JSON column on User)
- Nav visibility: Client-side fetch in Sidebar component
- Export: xlsx (already installed) + window.print()
- Page route: (app)/budget-planner/page.tsx (Next.js App Router)

5. PRISMA MODEL
===============

Add to prisma/schema.prisma:

  model BudgetPlannerItem {
    id          String   @id @default(cuid())
    userId      String
    type        String                    // "income" | "expense"
    category    String                    // e.g. "Home & Utilities"
    subcategory String                    // e.g. "Rent/Mortgage"
    amount      Float    @default(0)
    frequency   String   @default("monthly") // "weekly" | "fortnightly" | "monthly" | "yearly"
    sortOrder   Int      @default(0)
    createdAt   DateTime @default(now())
    updatedAt   DateTime @updatedAt

    @@index([userId, type])
    @@index([userId])
  }

Then run: npx prisma migrate dev --name add_budget_planner


6. API ROUTE IMPLEMENTATION NOTES
=================================

All routes follow the existing pattern from src/app/api/settings/route.ts
and src/app/api/export/route.ts:

  import { NextResponse } from 'next/server'
  import { prisma } from '@/lib/prisma'
  import { requireSession } from '@/lib/auth-helpers'

  export async function GET() {
    const session = await requireSession()
    const items = await prisma.budgetPlannerItem.findMany({
      where: { userId: session.id },
      orderBy: { sortOrder: 'asc' },
    })
    return NextResponse.json(items)
  }

PUT handler must verify ownership to prevent accessing other users' data:
  const item = await prisma.budgetPlannerItem.findUnique({
    where: { id: params.id },
  })
  if (!item || item.userId !== session.id) {
    return NextResponse.json({ error: 'Not found' }, { status: 404 })
  }


7. FREQUENCY CONVERSION LOGIC
=============================

Used in SummaryCard and Excel export:

  const monthlyMultiplier: Record<string, number> = {
    weekly: 4.33,
    fortnightly: 2.17,
    monthly: 1,
    yearly: 1 / 12,
  }

  function calculateMonthlyAmount(amount: number, frequency: string): number {
    return Math.round(amount * (monthlyMultiplier[frequency] ?? 1) * 100) / 100
  }


8. EXCEL EXPORT
===============

Uses existing xlsx package (already in package.json dependencies):

  import * as XLSX from 'xlsx'

  function exportToExcel(items: BudgetItem[]) {
    const data = items.map(item => ({
      Type: item.type === 'income' ? 'Income' : 'Expense',
      Category: item.category,
      Subcategory: item.subcategory,
      Amount: item.amount,
      Frequency: item.frequency,
      'Monthly Amount': calculateMonthlyAmount(item.amount, item.frequency),
    }))
    const ws = XLSX.utils.json_to_sheet(data)
    const wb = XLSX.utils.book_new()
    XLSX.utils.book_append_sheet(wb, ws, 'Budget')
    XLSX.writeFile(wb, `budget-planner-${new Date().toISOString().slice(0, 10)}.xlsx`)
  }

11. SIDEBAR NAV LINK DESIGN
===========================

Location: Sidebar.tsx, after the Finance nav item
The Sidebar is a 'use client' component, so we fetch preferences client-side:

  const [showBudgetPlanner, setShowBudgetPlanner] = useState(false)

  useEffect(() => {
    fetch('/api/settings')
      .then(r => r.json())
      .then(data => setShowBudgetPlanner(!!data.uiPreferences?.showBudgetPlanner))
      .catch(() => {})
  }, [])

Conditional rendering:
  {showBudgetPlanner && (
    <Link href="/budget-planner" ...>
      <Calculator className="h-4 w-4 shrink-0" />
      {!collapsed && 'Budget Planner'}
    </Link>
  )}

14. RISKS & EDGE CASES
======================

  - First visit with no items: Show empty state with "Load Defaults" CTA
  - Negative remaining balance: Color-coded red with friendly message
  - Zero-amount items clutter: Show but dim with opacity-50
  - SQLite float precision: Round to 2 decimal places on display
  - Sidebar toggle stale value: Acceptable -- refreshes on page navigation
  - Add item while already editing: Complete current edit first
