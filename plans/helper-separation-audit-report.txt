QUICK WINS (Phase 1 - Pure Function Extraction)
--------------------------------------------------------------------

  These can be done FIRST because they're pure functions with zero
  UI impact, immediately testable:

    1.  Extract finance-period.ts
        - Pure functions for period calculations
        - No UI impact, immediately testable

    2.  Extract tax-calculator.ts
        - Pure functions with ATO rates (critical to get right)
        - No UI impact, immediately testable

    3.  Extract list-mutations.ts
        - Eliminates ShoppingList/TodoList duplication immediately
        - Pure data transformation + API call pattern

    4.  Extract journal-helpers.ts
        - Shared by bills, income, and JournalEntryForm
        - Pure validation and computation

    5.  Extract account-ledger.ts
        - Simple formatting/CSV functions
        - Pure data transformation

  Each Quick Win follows the pattern:
    1. Create the lib file with extracted functions
    2. Add tests (if test suite exists)
    3. Import back into the source file
    4. Verify the import works and functionality is identical
